# Defect Reports

Create one copy of the template below for each defect confirmed during testing.

## Defect template
- **Defect ID:** BUG-001
- **Title:** Short, specific summary
- **Related test case:** TC__
- **Environment:** Browser, OS, app version
- **Severity:** Critical / High / Medium / Low (explain impact)
- **Priority:** High / Medium / Low (if your course uses priority)
- **Preconditions:** What must be true before reproducing
- **Steps to reproduce:**
  1. ...
  2. ...
- **Expected result:** ...
- **Actual result:** ...
- **Reproducibility:** Always / Sometimes / Once
- **Evidence:** screenshot filename and/or report link
- **Status:** Open / Fixed / Retest / Closed

Do not invent a defect. If no defects are found, write: “No defects observed in the executed test scope; this does not prove the entire application is defect-free.”
