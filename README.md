## 3. Requirements
- Python 3.10 or newer
- Google Chrome
- Internet connection for the first installation of Python packages

## 4. Setup and run (Windows)
Open a terminal in this repository folder:

```bash
py -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python run_app.py
```

Keep that terminal open. Open a second terminal in the same folder, activate the environment, and run:

```bash
.venv\Scripts\activate
pytest -v
```

On macOS/Linux, activate with `source .venv/bin/activate` instead. Selenium Manager normally locates/downloads a compatible browser driver automatically when required.

The tests use `http://127.0.0.1:8000`. Keep the demo server running while tests execute.

## 5. Scope
In scope:
- Required-field validation
- Successful appointment booking
- Rejection of a duplicate appointment slot
- Cancellation of a confirmed appointment

Out of scope:
- Real email/SMS delivery, payment, production security, and real patient data.
- This demo is educational and stores appointments in memory; restarting the server clears them.

## 6. Testing techniques
- **Equivalence partitioning:** valid and invalid required-field inputs.
- **Boundary value analysis (BVA):** past date versus today/future date (the demo rejects past dates).
- **Decision table:** complete valid form vs. missing required fields.
- **State transition:** Confirmed → Cancelled; a cancelled appointment is no longer shown as confirmed.
